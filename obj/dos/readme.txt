========================
qvplay,qvrecのMS-DOS化
 1996/12/23 Jun Suda
========================


0. はじめに

qvplay/qvrecは小さくて軽いとても素晴らしいソフトです。しかし、残念ながらMS-DOS上では動かすことができません。スモコンユーザーとしては是非ともDOS版が欲しいところです。「いっちょやったるかー」と思って移植(というほどのことはしていないのですが)してみました。


1. 使用するRS232Cのドライバーについて

qvplay on MS-DOSはRS232CのコントロールにRS232Cドライバーを必要とします。今回、用いているのは、Yassさんの作られた、Multi communication driver (MCD)のVersion 0.91です。転載可ということなので、Version 0.91は、私のホームページにおいてありますが、作者のYassさんが直接アップロードする場所として、
	NIFTY-Serve FBBSS,FGALTM,FGALTLB
	ASCII-NET pool msdos
などがありますので、本物(?)はそちらまでどうぞ。


2. MS-DOS版QVPlayの実行方法

まず、MCDというRS-232Cのドライバーを組み込む必要があります。詳しくは、MCDのパッケージにある説明をよく読んで設定して下さい。以下に一般的なマシン構成の場合の作業手順を示します。

1. md \mcd
2. cd \mcd
3. lha x mcd091.lzh
4. 起動ドライブの"config.sys"の最後に次の一行を追加
	device=c:\mcd\drivers\mcdpc.exe /D0AUX1    (AT機の場合)
	device=c:\mcd\drivers\mcd98.exe /D0AUX1    (98機の場合)
5. マシンを再起動して先ほど修正した"config.sys"の内容を有効にする
6. MS-DOS版の"qvplay.exe"/"qvrec.exe"を実行

(*) "/D0AUX1"の意味について
"0"はシリアルポート番号(0,1,2..)を意味する数字です。QV10がつながっているポートを指定してください。また、"AUX1"とはそのポートに割り当てるデバイス名です。MS-DOS版qvplayでは"AUX1"を標準デバイスとしています。


3. MS-DOS版QVPlayコンパイル方法

1. QVPLAY(Ver.0.1)のソース(QVPLAY01\SRC\*.*)を持ってくる
2. 本パッケージを上書きする(*.c,*.h,makefile,dospatch)
3. "patch < dospatch" としてqvplayのソースにパッチを当てます
4. makeする (turbo-c++ ver.4.0で確認しました。)


4. 仕様、問題点

1. 486SX25マシン+16550シリアルで、"top"スピードで動作を確認しています。
2. qvplayのフルサイズではjpegとcamファイルしか対応していません。(*)
3. ときどき暴走するかも知れません。
4. Turbo-C++ ver.4.0でしかコンパイルを確認していません。

(*) -F PPM,RGB,BMP
PPM,RBG,BMPなどを転送するためには、154KBの作業用メモリが必要なため。もうちょっと直せば動作するようにできると思うのですが...。でも、RGBで転送すると途方もない時間がかかりますよん。jpegで転送してからdjpeg.exeを使ってもどす方が早いのでそちらを使いましょう。(^^;)
